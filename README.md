# Grand Explorer

## About
探査機を操作して，太陽系を旅するゲームです．

姿勢変更や推進をコマンドで行い，探査機を操作します．

「CG画面」では，Godotによる3Dレンダリングでその衛星が置かれている雰囲気を感じることができます．(不完全ですが明るさ変更機能付きです)

「軌道設計画面」では，軌道ビューワーを使って探査機の軌道を客観的に見ることができます．任意の主星回りの予測されるケプラー運動を出したり，未来の惑星の位置を計算できます．

実装したい機能があまり実装できなかったため，「太陽系を旅するゲーム」というよりは「ケプラー運動を愛でるプログラム」という雰囲気ですが，ご了承ください．
(本当は遷移軌道とかスウィングバイ航法の設計ができるツールを作るつもりだったし，もっと探査機らしく電力とか観測機器とか残り燃料とか実装したかったんです…！)

## Implements

`src`以下にGodotのプロジェクトフォルダがそのまま入ています．
```
src
├── Benri.cs
├── Cal.cs
├── CannelLineBreak.cs
├── Canvas.cs
├── CelCon.cs
├── Main.cs
└── ほかGodot関連
```
すべてC#です．
`Main.cs`が全体の流れを管理するものです．定数の初期化・eventの対応・はここで行っています．

`Cal.cs`は便利な数学class・惑星の位置計算・軌道予測・暦関連・探査機の位置計算をする関数を含んでいます．

`Benri.cs`は，便利な機能(とくにdebug用)です．

`Canvas.cs`は，「軌道設計」タブでの描画を行っています．

`CelCon`は，「CG画面」で天体がうまく見えるように管理しています．(探査機は常に原点なので不動)
    遠方の描画うまくいってないですが…(shadingが適当すぎる)

\




惑星の位置はKepler方程式をNewton法で解いて計算しています．軌道要素は「惑星探査とやさしい微積分II」
より．

探査機の位置は，Leap-Frog法で微分方程式を計算しています．

軌道ビューワは，GodotのCustom Drawing 2Dで描画しています．(座標を指定すると直線が引けたり円が描ける機能)

機体の慣性モメントテンソルを決めてないので，姿勢変更は姿勢のquaternionを上書き
する適当な実装になっています・・・

探査機は，Blenderで3Dモデルを作成しました．とくに原作的なものはなく，完全に架空のものです．
探査機の主要諸元とか設定も全然詰めてないですね・・・
